### 1. Vozila — spec polja (cilindri, ventili, 0-100, maks. brzina)

**Problem:** `detail.mjs` template čitao polja `perf.zero_to_100_s` i `perf.top_speed_kmh` koji ne postoje ni u starom ni u novom JSON schema-u. Sva 107 vozila prikazivala `–` za performanse.

**Fix template** (`autouniverse-vozila/templates/detail.mjs`):
```js
// Čita iz sva 3 schema varijante
(perf.zero_to_100_s || perf.zero_to_100_kmh_seconds || e.acceleration_0_100_s)
(perf.top_speed_kmh || perf.vmax_kmh || e.top_speed_kmh)
```

**Migracija starih JSON-ova** (`scripts/migrate_engine_specs.py`):
- 48 fajlova (stari schema, root-level `schema_version: "0.4"`) — dodati `cylinders` + `valves_per_cylinder`
- 59 fajlova (novi schema) — preskočeni (polja već postoje)
- Heuristika: V8=8cyl, V6=6cyl, 16V=4vpc, 1.0/1.2/1.4 TDI/TSI = 3cyl, itd.

**Git commit:** `9d13fa5` (D:\BELORA root repo — 50 fajlova: 48 JSON + 2 skripte)

### 5. Autodelovi — AU Core auth integracija

**Commit:** `3960b69`

#### Backend — `autodelovi/routes/parts.js`
- `PUT /parts/:id`: sad prihvata AU Core session pored starog `x-seller-token` (isti pattern kao DELETE)
  - `okViaSession = auUser && part.user_id === auUser.id`
  - `okViaToken   = token && part.seller_token === token`
  - Backward compat: stari oglasi (bez `user_id`) i dalje rade via token

#### Frontend — `autodelovi/public/index.html`

**Prodaj tab — auth gate:**
- Inicijalno prikazuje login formu (email + lozinka)
- POST → `https://hub.autouniverse.rs/auth/login` → čuva `sessionId` kao `au_token` u localStorage
- Posle prijave: zeleni user bar "Prijavljeni ste kao [ime]" + logout dugme
- Forma se pre-filluje imenom iz AU Core profila
- `submitOglas()` dodaje `Authorization: Bearer <token>` header

**Moj oglas tab — Vaši oglasi sekcija:**
- `GET /parts/mine` (zahteva AU session token) → lista korisnikovih oglasa
- Svaki oglas: naziv, cena, kategorija, status (zeleno/žuto/plavo), broj pregleda
- Dugmad: Aktiviraj / Pauziraj / Prodato / Obriši — sve ide via AU session token
- Stari seller_token form ostaje ispod (backward compat)

**Session management:**
- `checkAuSession()` se poziva na `DOMContentLoaded` i proveri `localStorage.au_token` → GET `hub.autouniverse.rs/auth/me`
- `switchTab('sell')` i `switchTab('seller')` pozivaju `renderSellTab()` / `renderMineSection()`
- `auLogout()` briše token iz localStorage, resetuje UI
