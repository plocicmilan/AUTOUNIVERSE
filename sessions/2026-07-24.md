## AU Core API — aktualno stanje ruta

```
Auth:          POST /auth/register, /auth/login, /auth/logout, /auth/me, /auth/change-password
Accounts:      GET/PUT /accounts/me
Vehicles:      GET/POST /vehicles, GET/PUT/DELETE /vehicles/:id, GET /vehicles/:id/grants
Events:        POST /vehicles/:id/events, POST /vehicles/:id/events/batch
               GET /vehicles/:id/events, GET /vehicles/:id/events/summary
               GET/PUT/DELETE /vehicles/:vid/events/:eid
Notes:         POST/GET /vehicles/:vid/notes, DELETE /vehicles/:vid/notes/:nid
Reminders:     POST /vehicles/:vid/reminders/batch (NOVO)
               POST/GET /vehicles/:vid/reminders
               PUT/DELETE /vehicles/:vid/reminders/:rid
Grants:        POST/DELETE /grants, GET /grants/mine (NOVO), GET /vehicles/:id/grants
Notifications: GET/POST /notifications, DELETE /notifications/:id, POST /notifications/clear
Share:         POST /share, GET /share/:token, POST /public/share, GET /public/share/:token
Admin:         GET /admin/users, POST /admin/users/:id/approve
Stats:         GET /stats, GET /health
```
